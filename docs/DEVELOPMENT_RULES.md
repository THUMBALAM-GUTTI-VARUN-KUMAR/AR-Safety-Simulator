# AI Development Rules

Rules for developers and AI agents:

1. AI must work only inside the developer's assigned module.
2. AI must follow `ARCHITECTURE.md`.
3. AI must follow `API_CONTRACT.md`.
4. AI must not redesign the architecture without team approval.
5. Do not generate the whole application in one prompt.
6. Build one feature at a time.
7. Test every generated feature.
8. Commit working code.
9. Never paste real API keys or passwords into prompts.
10. Never accept generated safety procedures without human verification.
11. Do not add dependencies unless the team approves them.
12. Keep the application optimized for mid-range Android devices.
