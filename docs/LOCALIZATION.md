# Localization Dictionary

This document contains localized strings for the `SIM_GAS_LEAK_01` scenario targeting the Jharkhand workforce. 
The application supports dynamic switching between English, Hindi, and Santali.

| :--- | :--- | :--- |

| `INTRO_BODY` | A toxic and explosive gas leak has been detected. | एक जहरीली और विस्फोटक गैस का रिसाव पाया गया है। (Ek jahrili aur visfotak gas ka risav paya gaya hai.) |
